[2026-10-10] Fix: Async Client Storage, Zoom/Scroll Readability & Desktop Launcher
- Resolved Issue 1 (Account registry "Timeout waiting InvokeMethod clientStorage" error):
  * Root Cause: Calling synchronous `page.client_storage.set()` within asynchronous event handlers blocked the asyncio thread waiting on `threading.Event`, preventing Flet's underlying WebSocket event loop from receiving the bridge response.
  * Fix: Migrated to non-blocking `await page.client_storage.set_async()` in `frontend/views/login.py` and `await page.client_storage.remove_async()` in `frontend/components/navigation.py`.
- Resolved Issue 2 (Page sizing, scrollability, and zoomability):
  * Configured default desktop window dimensions (1200x850, min 800x600, resizable=True) in `frontend/main.py`.
  * Enabled `scroll=ft.ScrollMode.AUTO` across all views (`login_view`, `dashboard_view`, `settings_view`) to eliminate viewport clipping.
  * Implemented `frontend/components/zoom.py` providing interactive on-screen zoom toolbars (`[-]`, `[+]`, `[Reset]`), dynamic scale transformation, responsive extra padding, and global keyboard shortcuts (`Ctrl +`, `Ctrl -`, `Ctrl 0`).
- Resolved Issue 3 (Clickable launcher):
  * Created `run_frontend.bat` in the workspace root with automated Conda environment activation (`BMEnv`) and graceful fallback execution.
